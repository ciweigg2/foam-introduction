以下截图来自 FoamV2 Web 端实际界面，演示数据均为测试内容。界面和功能可能随版本更新略有调整。

## 🔐 登录与账号入口

支持账号密码登录、Telegram 登录、卡密激活、用户注册、邀请码注册及初始化管理员等入口。

[![FoamV2 Web 登录页](../imgs/screenshots/1.png)](../imgs/screenshots/1.png)

[![FoamV2 Web 首页](../imgs/screenshots/2.png)](../imgs/screenshots/2.png)

## 🤖 媒体库

媒体库信息、画质音质、入库状态

[![FoamV2 Web 媒体库](../imgs/screenshots/3.png)](../imgs/screenshots/3.png)

## 🤖 求片信息
