# 🫧 FoamV2

Foam 是一套面向 Emby 的多服务器管理与用户服务平台，集成 Web 管理后台、用户中心、播放分析、求片订阅、积分娱乐、分销系统与 Telegram 机器人。

## 🌐 Web 端功能

### 🔐 登录与账号

- 支持账号密码登录、Telegram 登录和多服务器账号选择
- 支持普通注册、邀请码注册、卡密激活和初始化管理员
- 支持扫码购买激活卡密、查询支付订单
- 支持修改个人资料、密码、头像和联系方式
- 支持 Telegram、Rose 账号绑定及线路测速
- 支持 PWA 安装、多主题切换、站内公告和全局媒体搜索

### 🎬 媒体与求片

- 仪表盘展示服务器状态、馆藏统计、最新入库、播放趋势和热门排行
- 浏览 Emby 媒体库，查看影片、剧集、分季分集、演职人员和媒体规格
- 基于 TMDB 搜索电影与剧集，查看趋势、热门内容和预告片
- 支持整部求片、按季求片、求片次数限制和入库状态检测
- 支持求片审核、拒绝、入库和历史记录管理
- 支持 MoviePilot 订阅管理、缺集查看和取消订阅
- 支持用户提交工单及管理员回复处理

### 👥 用户管理

- 用户查询、创建、编辑、启用、禁用、删除和密码重置
- 支持白名单用户、有效期、求片次数、管理员和分销商角色管理
- 支持多服务器集群开户、跨服务器用户同步和用户对比
- 支持批量延期、批量修改到期时间和批量删除
- 支持管理员菜单权限分配与超管员保护
- 支持检测用户 Telegram 群成员状态并生成处理报告
- 支持 Telegram 绑定、解绑、换绑审批和统计排行
- 支持注册记录、续费记录、卡密和邀请码管理

### 📊 播放分析与安全

- 实时查看正在播放、暂停状态、客户端和播放进度
- 查看播放记录、播放趋势、热门影片和用户播放排行
- 播放汇总支持用户、设备、IP、地区和世界地图分析
- 用户分析支持播放次数、时长、活跃度和禁用记录统计
- 支持同时播放检测，以及全局、服务器、用户级并发限制
- 支持客户端 UA、国家、地区、省州访问拦截
- 支持访问排除用户、拦截记录和风险统计

### 🎮 积分与娱乐

- 用户可查看积分余额、等级、积分流水和兑换记录
- 支持积分注册 Emby 账号、账号续费和奖品兑换
- 支持签到、发言积分、积分转账、排行榜和抽奖
- 支持群积分红包、领取记录、取消红包和剩余积分退回
- 支持泡沫袋积分领取、归还、逾期处理和规则配置
- 后台支持兑换配置、等级配置、奖品配置和积分调整
- 支持 Brain、三国杀、21 点、骰子、地狱骰、老虎机和泡沫刮刮乐

### 🛍️ 分销与支付

- 分销商可查看积分、用户、卡密和经营数据
- 支持提交进货申请、积分商城兑换和兑换历史
- 支持分销卡密管理及注册用户统计
- 管理员可审核进货、审核自定义兑换并管理商品
- 支持售卡套餐、支付方式、订单超时和自动查单配置
- 支持支付记录、订单详情、重新查单和人工确认发卡

### ⚙️ 系统管理

- 支持管理多个 Emby 服务器、访问地址、API Key 和线路
- 支持线路展示、白名单线路和延迟、抖动、下载测速
- 支持全局或指定用户的媒体库分级权限
- 支持自动生成 Emby 媒体库封面
- 支持 TMDB 追新日历、定时同步和多渠道推送
- 支持站内公告、通知渠道和通知模板管理
- 支持 Telegram、钉钉、企业微信和消息推送助手
- 支持实时日志、定时任务、CRON 修改和立即执行
- 支持旧版 Foam 与 EmbyBoss 数据迁移
- 支持系统配置、授权激活和设备解绑

## 🤖 Telegram 机器人功能

### 🔗 账号服务

- 按钮式 `/start` 服务面板
- 查询绑定账号和可用线路
- 绑定、解绑和换绑 Emby 账号
- 支持绑定审批、机器人内审批和用户自助取消
- 支持 Telegram 登录 Web 端
- 支持私聊注册、卡密开号和卡密续费
- 多服务器同名账号可选择目标服务器

### 🔍 Telegram 求片

- 私聊发送 `/request 片名` 搜索 TMDB 并提交求片
- 支持 `@机器人 片名` 内联搜索求片
- 自动检查账号绑定和媒体入库状态
- 支持每日免费次数、超额扣积分和拒绝自动退款

### ⭐ 积分互动

- 每日签到、连续签到奖励和随机奖惩
- 群聊发言积分、积分查询、排行榜和积分转账
- 积分注册账号、账号续费和奖品兑换
- Telegram 抽奖、群积分红包和泡沫袋
- 支持积分流水、退款和异常操作保护

### 🎲 群聊游戏

- Brain 脑力挑战
- 三国杀积分对局
- 21 点
- 骰子比大小
- 地狱骰与地狱之王排行
- 老虎机
- 泡沫刮刮乐

### 🛡️ Telegram 管理

- 查询用户并打开聊天内管理面板
- 管理白名单、账号状态、有效期和密码
- 创建用户、批量延期和批量生成卡密
- 设置用户媒体库分级
- 向已绑定用户批量发送公告
- 管理抽奖、积分和地狱骰金库
- 支持禁言、解除禁言、踢出封禁和开户邀请
- 支持按管理员分别分配机器人操作权限
- 可选退群自动解绑及删除普通 Emby 账号

### 🔔 Telegram 通知

- Emby 新媒体入库通知
- 播放开始、暂停、停止和登录认证通知
- 用户到期、禁用、删除及同时播放告警
- 求片提交、审核、拒绝和入库通知
- 注册、续费和卡密使用通知
- 每日播放排行榜海报
- TMDB 追新日历推送
- Telegram 绑定审批和处理结果通知

> 部分功能需要在后台开启对应配置，并根据普通用户、管理员、超管员或分销商权限显示。
